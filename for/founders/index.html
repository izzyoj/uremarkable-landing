Honest Limitations

What you should know before you book

No spin. The constraints are real, and they're worth naming upfront.

macOS or Windows required
Claude Desktop runs on Mac and Windows. Linux is not currently supported. All scheduled and agentic tasks require the machine to be awake and Claude Desktop running.
Pro or Max plan required
Dispatch (scheduled automation) requires a Claude Pro (A$30.91/mo) or Max plan (A$154.54/mo+). The free tier does not support background agent tasks.
Not a one-off project
Agents need maintenance. Workflows change, prompts drift, connected tools update. The retainer model exists because a one-off build without ongoing support degrades over time. If you want a handoff, this is not the right service.
We pick the workflows
The discovery session exists to find the right workflows, not to build whatever you have in mind on day one. High-effort, low-value automations don't get built. That's part of the service.
