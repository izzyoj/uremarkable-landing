Setup walkthrough

How it's built in Cowork

Seven steps from nothing to live. The Cowork project is the container — everything else runs inside it.

0
Create your Cowork project
Before any connectors or tasks, create a dedicated Cowork project for your agency. Each project has its own instructions, scheduled tasks, and memory — scoped to you, not shared across clients or setups. Open Cowork, click New project, name it (e.g. "Ray White North Shore — Lead Follow-Up"), and set the context: point it at your local listings folder. This is the container. Everything below runs inside it.
New project • scoped memory • your agency only
1
Install the plugin
Open Cowork, click Customize in the left sidebar, then Browse plugins. Upload the Lead Follow-Up plugin file. One click install, everything bundled: skills, connectors, scheduled tasks, CRM schema.
Cowork Plugin file • one upload
2
Set global instructions
Go to Settings > Cowork > Global Instructions. Tell Claude your agency name, your preferred communication style, and the number your SMS will send from. These instructions apply to every follow-up it writes.
Settings → Cowork → Global Instructions
3
Connect Gmail MCP
The plugin reads your Gmail for new enquiry notifications from REA and Domain. Authorise the Gmail connector in Cowork. Claude watches for the subject line patterns that indicate a new lead has arrived.
Claude Settings → Connectors → Gmail
4
Connect Twilio MCP
SMS sends from a Twilio-provisioned business number, not your personal mobile. Set up a Twilio account, provision a number for your agency, then add the Twilio MCP credentials in Cowork. The buyer sees your agency's number every time.
Twilio → provision number → add MCP
5
Connect Google Sheets MCP
Every lead gets logged automatically. Create a Google Sheet with the lead tracking template included in the plugin, then authorise the Google Sheets connector. Name, property, enquiry type, source, timestamp, SMS sent, email sent, status.
Google Sheets → template → connect MCP
6
Schedule and activate Dispatch
In any Cowork task, type /schedule to set up the hourly automated check. Then open the Dispatch tab to link your mobile app. From that point, Claude runs automatically every hour and pushes notifications to your phone when action is needed.
/schedule • Dispatch • mobile linked
Two ways to respond

Automated coverage meets on-demand speed

The automation runs on two modes. Both happen through the same plugin. Which you lean on depends on how your day is running.

⏱
Automated hourly
Claude checks for new enquiries every hour while your Desktop is open. Every lead that came in since the last check gets a follow-up automatically, no input needed.
Best for: morning batches, overnight enquiries, open home follow-ups. You come back to a completed run.
✓ Hourly minimum cadence (Anthropic's scheduling limit)
📲
On-demand via Dispatch
A new enquiry just came in while you're at an inspection. Open the Claude mobile app, type: "Send follow-up for the Mosman lead." It runs on your desktop. Result lands in the thread.

What to know before you set up

Honest limitations

This is real infrastructure, not a demo. Here's exactly what it requires and where the edges are.

💻
Desktop must stay open. Scheduled tasks only run while your computer is awake and the Claude Desktop app is active. If your machine sleeps, Cowork skips the run and catches up when it wakes. Source: Anthropic — Schedule recurring tasks in Claude Cowork
⏱
Automated minimum cadence is one hour. Cowork's scheduler runs no faster than hourly. For faster response when you're active, use Dispatch to trigger on-demand from your mobile. Source: Anthropic — Schedule recurring tasks in Claude Cowork
🌐
MCP connectors need a public internet endpoint. Connectors route through Anthropic's cloud. If your agency's systems are behind a private network, they'll need to be exposed to a public URL first. Source: Anthropic — Use plugins in Claude Cowork
📱
Dispatch requires both the Desktop and mobile apps. The mobile app sends the task. The desktop runs it. Both need to be installed and the desktop must be active. Available on Pro and Max plans. Source: Anthropic — Assign tasks from anywhere in Claude Cowork
💳
Cowork uses more of your usage allocation than regular chat. Complex multi-step tasks consume more tokens. If you're on the edge of your plan's limit, run simpler tasks in standard chat and reserve Cowork for automation work. Source: Anthropic — Get started with Claude Cowork
