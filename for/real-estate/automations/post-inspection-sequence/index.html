Setup walkthrough

How it's built in Cowork

Six steps from nothing to live. You leave the setup session with a running system, not a configuration checklist.

0
Create your Cowork project
Create a dedicated Cowork project for your agency's inspection workflow. Name it clearly (e.g. "Ray White Mosman: Post-Inspection"). Each project keeps its own memory and instructions, separate from any other automation you're running.
New project • scoped to your agency
1
Install the plugin
Open Cowork, click Customize in the left sidebar, then Browse plugins. Upload the Post-Inspection Sequence plugin file. One upload installs everything: the note schema, message templates, Sheets connector, Gmail or Outlook connector, and Dispatch integration.
Cowork Plugins • one upload
2
Set your agency instructions
Go to Settings > Cowork > Global Instructions. Tell Claude your name, your agency, your communication style, and the property address format you use. This shapes every message it writes so they sound like you, not a template.
Settings → Cowork → Global Instructions
3
Connect Google Sheets
Create your inspection log using the template included in the plugin. One row per buyer: name, phone, email, property, inspection date, what they liked, their concern, interest level. Authorise the Sheets connector. The plugin reads from and writes to this sheet automatically.
Google Sheets → template → connect MCP
4
Connect your agency email and Twilio
The Day 1 message sends as SMS from your agency's Twilio number. Day 2 and Day 7 messages send from your agency email (Gmail or Outlook / M365 both work). Authorise both connectors in Cowork. From that point, the plugin can send without you touching your phone.
Gmail or Outlook MCP • Twilio MCP • both in one session
5
Set the trigger and activate Dispatch
The plugin fires when a new inspection row is added to your Sheet. Set that trigger in Cowork using /schedule or the trigger config inside the plugin. Then link Dispatch so you get a mobile notification before each message sends. You review, approve with one tap, or let it run fully automated.
Trigger on new row • Dispatch linked • live
What to know before you set up

Honest limitations

This is real infrastructure. Here's exactly what it requires and where the edges are.

💻
Desktop must stay open. Scheduled tasks only run while your machine is awake and Claude Desktop is active. If your computer sleeps mid-sequence, the next message runs when it wakes. For same-day follow-ups, keep the machine on when you get home from inspections. Source: Anthropic: Schedule recurring tasks in Claude Cowork
⏭
Notes need to be in the Sheet before the sequence runs. The plugin reads from your inspection log. If you haven't entered the buyer notes yet, the sequence won't have the context it needs. Add notes before you leave the property or batch them on the drive home. How it works: Google Sheets trigger
📱
Dispatch requires both Desktop and mobile apps. The approval notification goes to your mobile. The actual send happens on your desktop. Both need to be installed. Available on Pro and Max plans only. Source: Anthropic: Assign tasks from anywhere in Claude Cowork
💬
SMS sends from a Twilio number, not your mobile. Buyers receive the Day 1 message from your agency's dedicated business number. That's by design, not a limitation. But it does mean setting up a Twilio account before you go live (about 10 minutes). Twilio setup: one-off, included in the setup session
