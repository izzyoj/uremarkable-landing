Setting Up Cursor

Cursor is a free AI-powered code editor that doubles as a troubleshooting tool. When something breaks with your Claude setup, Cursor can diagnose errors, explain what they mean, and tell you exactly what to run to fix them. This guide covers installing it and using it effectively.

Part 1 — Install Cursor
1
Download Cursor
Go to cursor.com and click the download button. It detects your OS automatically.
Free tier gives you 500 AI requests per month. That is more than enough for occasional troubleshooting.
2
Install it
Open the downloaded file (it will be in Downloads). Drag the Cursor icon into your Applications folder when prompted. Then open Cursor from Applications or Spotlight (Cmd+Space, type "Cursor").
3
Sign up for a free account
Cursor will ask you to sign in on first launch. Create a free account with your email. No credit card needed.
Part 2 — Open a Folder for Troubleshooting
4
Open your project folder in Cursor
In Cursor, go to the top menu: File > Open Folder

Navigate to the folder your setup provider configured for you. This is where your CLAUDE.md file and project files live. Click it once to select it, then click Open.
Not sure which folder? Press Cmd+Shift+H in the folder picker to jump to your home folder. Your setup provider will have named the folder clearly during your setup session.
5
Confirm you are in the right place
Once open, you will see a list of files on the left panel. You should see your CLAUDE.md file. If you see it, you are in the right folder.
If you see something completely different or a blank panel, close and try File > Open Folder again.
Part 3 — Open the Terminal Inside Cursor
6
Open a terminal panel
Go to the top menu: Terminal > New Terminal

A terminal panel opens at the bottom of the screen, pointed at your project folder. You are ready to type commands.
Shortcut: Ctrl + ` (backtick key, above Tab)
7
Confirm you are in the right place
In the terminal, type this and press Enter:
pwd
It should show the path to your project folder. If it does, you are in the right place.
Part 4 — Asking Cursor AI for Help
8
Open the AI chat
Press Cmd+L to open the Cursor AI chat panel on the right. This is where you describe what broke and get step-by-step help.
9
What to say when something breaks
Describe the problem in plain English and paste any error text. Examples:
"Claude Desktop stopped responding after I restarted my Mac. How do I get it running again?"

"I got this error when trying to use a connector: [paste the red text here]. What does it mean and how do I fix it?"

"How do I check if my scheduled workflows are still running?"
Cursor AI can read the files in your project folder. It will give you the exact commands to run, explained in plain English. Copy and paste them straight into the terminal panel below.
Quick Reference — Keyboard Shortcuts

Cmd + L
Open terminal panel
Ctrl + `
Open a folder

Jump to home folder (in file picker)

New terminal tab

Still stuck?
If Cursor AI cannot fix it, send support a screenshot of the red error text. Most issues can be diagnosed and resolved remotely in a few minutes.
