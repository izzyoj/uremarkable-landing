Full coverage model (everything through AI first) = ~100% of calls routed, agent triaged post-qualification. Typical monthly cost for a median agent (85 calls × 3.5 min): ~$38.75 USD / ~$61 AUD standard stack.

Partial coverage model (after-hours + overflow only, ~60% of calls) = ~50 calls × 3.5 min: ~$22.75 USD / ~$36 AUD standard stack. Recommended starting point for beta to ease agents into it.
