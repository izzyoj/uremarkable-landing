How it is built in Cowork
Six setup steps. One session. The plugin runs from that point on.
1
Create a new Cowork project
Open Claude Desktop, create a project called something like Apex Trades: Quoting. This is the memory container. Everything specific to your quoting workflow lives here.
2
Connect your agency email
Add the Gmail MCP or Outlook MCP connector. Cowork sends all quotes from your connected email address, so clients see it coming from you directly, not from a third-party tool.
3
Upload your rate card
Add a rate card file to the project. A simple spreadsheet or plain text doc works: line item names, units (sqm, lot, hr), and your prices. Cowork reads this every time it builds a quote.
4
Set your quote template in instructions
In the project instructions, tell Cowork your quote numbering prefix (e.g. APX-), your payment terms (50% deposit, balance on completion), quote validity (30 days), and any standard scope exclusions. Set once, applies to every quote.
5
Connect your pipeline
Add a Google Sheets MCP connector and link a simple quote tracker sheet. Cowork logs every quote sent: client name, job type, value, date, status. If you use HubSpot, Salesforce, or Pipedrive, those connect natively. Rex, PropertyMe, and others connect via Zapier MCP.
6
Add your follow-up schedule
Create two scheduled tasks: Follow-up 1 at Day 5, Follow-up 2 at Day 10. Tell Cowork to check the pipeline for quotes with no response and draft a follow-up for each one. You review and approve in Dispatch before anything sends. Claude Desktop needs to be running for scheduled tasks to fire.
